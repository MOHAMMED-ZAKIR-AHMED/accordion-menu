# accordion-menu
Simple Accordion Menu using pure HTML &amp; CSS
Accordion Menu (HTML & CSS)

A simple and clean Accordion Menu built using pure HTML & CSS.
No JavaScript used — just smooth and responsive accordion animation using CSS only.

✨ Features

Pure HTML & CSS (No JS)

Smooth open/close accordion effect

Clean and minimal UI

Beginner-friendly code structure

Easy to customize

📁 Project Structure
/
├── index.html
└── style.css

🚀 How to Use

Download or clone the project

Open index.html in any browser

Use the accordion menu with smooth animations
